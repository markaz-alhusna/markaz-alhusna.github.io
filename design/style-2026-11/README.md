Каркас — это скриншоты того, как экраны устроены сейчас: какие разделы, кнопки, таблицы. Структуру сохраняем, внешний вид рисуешь заново. Если какой-то блок лучше переставить или убрать, предлагай.

## Что делаем сейчас

1. **Кабинет учителя и панель админа** — новый стиль (оливка, песочный, бежевый, без золота).
2. **Сайт садика** — перерисовать готовый сайт в новом стиле.
3. **Сайт мадрасы** — перерисовать готовый сайт в новом стиле.

Главную страницу и Марказ пока не трогаем. Каркас главной уже лежит в `karkas/glavnaya/`, чтобы можно было заранее посмотреть; задание по ней дадим отдельно.

## Как присылать

Сначала макеты и промежуточные варианты, чтобы сразу давать правки:

1. 2–3 варианта настроения одного экрана (например, расписание учителя).
2. Черновые макеты главных экранов.
3. Промежуточные версии по ходу работы.
4. Финал и набор стиля (цвета с кодами, шрифты с размерами, кнопки, иконки) — только после утверждения макетов.

Каждую версию клади в отдельную папку:

```
makety/kabinety/v1/
makety/kabinety/v2/
makety/sadik/v1/
makety/madrasa/v1/
```

Формат любой: PNG, PDF или ссылка на Figma (ссылку можно положить текстовым файлом `figma.txt`).

## Как загрузить в GitHub

1. Открой нужную папку, например `makety/kabinety`.
2. Нажми **Add file → Upload files** и перетащи с компьютера папку `v1` целиком (внутри — твои файлы). GitHub сохранит её как папку.
3. Внизу GitHub предложит создать ветку и запрос на изменения — соглашайся (**Propose changes → Create pull request**). Меля примет.
4. Напиши Меле, что загрузила.
