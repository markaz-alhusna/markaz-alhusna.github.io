# Джамиля, пробное задание: комната «Дом» для уроков ОБЖ (садик)

Ас-саляму алейкум! Здесь всё, что нужно: что сделать, как назвать файлы и как сдать.

## 1. Принять приглашение
Открой https://github.com/markaz-alhusna/markaz-alhusna.github.io/invitations и нажми **Accept invitation**.

## 2. Что сделать
Одна комната и предметы для 6 уроков ОБЖ (безопасность дома) для детей 4–7 лет.

**Стиль:** объёмные глянцевые 3D-предметы, мягкий свет, светлые чистые цвета, как дорогая детская игрушка-иллюстрация. Без людей, лиц, глаз, животных и мишек.

Каждый предмет — отдельный файл `.glb`. Имена файлов строго такие, по ним их находит код:

| Файл | Предмет |
| --- | --- |
| room.glb | сама комната: пол, стены, окно, кухонный уголок |
| stove.glb | плита |
| kettle.glb | чайник |
| pot.glb | кастрюля |
| knife.glb | нож |
| iron.glb | утюг |
| outlet.glb | розетка |
| wire.glb | провод |
| matches.glb | спички |
| pills.glb | таблетки |
| tower.glb | высокая полка / шкаф |
| box.glb | коробка |
| flashlight.glb | фонарик |

Плюс к каждому предмету: исходник (Blender или другой) и картинка PNG на прозрачном фоне.

## 3. Технические требования
- Формат glTF binary (`.glb`), один файл до 2 МБ, текстуры до 1024×1024.
- Масштаб в метрах, предмет стоит на полу (низ = 0), по центру.
- Без анимаций и камер внутри файла.

## 4. Как сдать
1. Открой эту папку: https://github.com/markaz-alhusna/markaz-alhusna.github.io/tree/main/design/trial
2. **Add file → Upload files**, перетащи файлы.
3. Внизу выбери **Create a new branch** (имя, например, `jamila-trial`) → **Propose changes** → **Create pull request**.
4. Можно сдавать частями: потом загружай в ту же ветку, всё попадёт в тот же pull request.
