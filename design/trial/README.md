# Пробное задание дизайнера: комната «Дом» для уроков ОБЖ (садик)

Одна комната и предметы для 6 уроков ОБЖ. Стиль садика: объёмные глянцевые 3D-предметы, мягкий свет, без людей и лиц.

## Что загрузить
Каждый предмет отдельным файлом `.glb`, имена файлов строго такие (по ним их находит код):

| Файл | Предмет |
| --- | --- |
| room.glb | сама комната (пол, стены, окно, мебель) |
| stove.glb | плита |
| kettle.glb | чайник |
| pot.glb | кастрюля |
| knife.glb | нож |
| iron.glb | утюг |
| outlet.glb | розетка |
| wire.glb | провод |
| matches.glb | спички |
| pills.glb | таблетки |
| tower.glb | высокая полка / шкаф (опасная высота) |
| box.glb | коробка |
| flashlight.glb | фонарик |

Плюс: исходник (Blender или другой) и рендер PNG каждого предмета.

## Требования
- Формат glTF binary (.glb), размер одного файла до 2 МБ, текстуры до 1024×1024.
- Масштаб в метрах, предмет стоит на полу (низ = 0), центр по горизонтали в 0.
- Без анимаций и камер внутри файла.

## Как загрузить
Add file → Upload files → внизу «Create a new branch» → Propose changes.
